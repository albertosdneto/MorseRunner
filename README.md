# Morse Runner Py
Based on the Morse Runner by Alex Shovkoplyas, VE3NEA

Check the original application at http://www.dxatlas.com/MorseRunner/

## Disclaimer
This is a personal project. For my own amusement.
This project (at least for now), although based on someone else's work, 
has no relation to the original project or author.


## Setup
Once you have cloned this project locally, enter the directory and create
a virtual environment with python 3.13. I have uses pyenv.
```
pyenv virtualenv 3.13.1 morserunner
pip install -r requirements.txt
```
